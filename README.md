## Setup

Before running BOLT, make sure everything is placed in the correct location:

```text
BOLT/
├── bolt.bat
├── config.json
├── proxies.txt
└── combos/
```

### Proxies

Put your proxies inside:

```text
proxies.txt
```

### Combos

Put your combo files inside the:

```text
combos/
```

folder.

### Configuration

Settings can be changed inside:

```text
config.json
```

Edit the configuration as needed before launching.

---

## Running BOLT

Run:

```bat
bolt.bat
```

Once BOLT starts, select the module you want to load from the menu.

## Quick Start

1. Add proxies to `proxies.txt`
2. Add combos to the `combos/` folder
3. Configure your settings in `config.json`
4. Run `bolt.bat`
5. Select the module you want to load
